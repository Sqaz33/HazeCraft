# Haze для Minecraft — личный проект

Промежуточная сборка **0.3.6-ground-crouch**. Данные движения взяты из вашей Deadlock **25950029 / клиент 6785**. Исправлены воздушный прыжок по повторному Space, обработка коротких нажатий, физика воздушного рывка и боковых отскоков. Точное совпадение всей системы движения, камеры и интерфейса пока не достигнуто. Отличия и проверки записаны в MOVEMENT_RESEARCH.md и MODLOG.md.

В 0.3.1 модель отправляет 49 632 общие вершины вместо 314 814 повторяющихся вершин за кадр. Все исходные треугольники и анимации сохранены. В тестовой сцене без ограничения FPS частота кадров выросла примерно со 117 до 348; это измерение лаборатории, а не гарантия для любого мира. Подробности — PERFORMANCE.md.

В 0.3.2 цикл ходьбы и бега переведён на локальную временную шкалу с общей фазой шага при смене семейства анимаций. Скорость для смешивания поз интерполируется между игровыми тиками. По запросу пользователя эта версия собрана без тестов и игровых проверок.

## Запуск текущей сборки

Minecraft **1.21.11**, **Java 21+**, **Fabric Loader 0.19.5+**. Поместите `dist/deadlock-haze-0.3.6-ground-crouch.jar` в папку `mods` этой версии Minecraft, заменив прежний JAR Haze. Fabric API включён внутрь JAR. Для первого запуска используйте отдельный мир.

- **F6** — Стив / Haze.
- **F8** — меню отладки, только в креативе. F8 / Esc закрывает меню; мир продолжает работать.
- **W A S D** — движение; **Shift** — рывок; **Ctrl** — приседание / скольжение; **Space** — прыжок.
- **ЛКМ** — стрельба; **ПКМ** — прицеливание; **R** — перезарядка.
- **1** — Sleep Dagger; **2** — Smoke Bomb; **3** — пассивная Fixation; **4** — Bullet Dance.
- **Q** — удар; **F** — парирование.
- Удерживайте **Alt** для курсора и улучшений; **Alt + 1–4** улучшает соответствующее умение. Очки способностей бесконечны.

Канат и зиплайн исключены по вашему требованию.

Повторное нажатие **Space в воздухе** выполняет воздушный прыжок с импульсом 525 единиц Source; рядом со стеной выполняется отскок. Во время Haze двойной Space не включает полёт творческого режима. Быстрая регенерация стамины (×10) и бесконечные патроны во время скольжения сохранены по вашему запросу.

Скелет и потоки анимаций остаются ранее преобразованными ресурсами вашей игры, с сохранённым исправлением корневого движения и ножа. Привязки анимаций прыжков обновлены по текущим графам. Наклоны поверхностей и взаимодействия всех состояний ещё требуют доводки.

JAR содержит преобразованные ресурсы вашей Deadlock и предназначен для личного использования. Ничего не загружается в интернет. Проект и локальный Git находятся на диске D:. Извлечённые ресурсы игры исключены из Git.

## Сборка

`Build.ps1` запускает программные проверки и создаёт JAR в `build/libs`; `python tools/package_preview.py` проверяет и копирует итог в `dist`. Подготовленные личные ресурсы необходимы для сборки. Конвертеры и лабораторные данные описаны в MODLOG.md. Тестовый сценарий Minecraft включается только специальным параметром разработки.


## Меню отладки (0.3.3)

F8 работает в креативе как у Стива, так и у Haze. Меню показывает скорость,
стамину, состояние прыжков/дэша/стен, HP, патроны, КД, текущую анимацию и FPS.
Кнопки: Стив/Haze, восстановление HP/патронов/КД, стамина, сброс движения,
манекен на 10 000 HP, удаление своих манекенов в пределах 64 блоков и
переключатель «Умения без КД». Манекены неподвижны и получают урон/эффекты.

Режим без КД поддерживает готовность способностей и заряды дыма; задержки
применения, длительность эффектов и ограничения во время ульты сохраняются.
При выходе из креатива меню закрывается и режим без КД отключается. Действия
над здоровьем, патронами, способностями и мобами также проверяются сервером.
Сборка прошла программные тесты; игру для проверки этой версии не запускали.


В 0.3.4 исправлено заполнение наклонённого названия длительности умения:
обрезка выполняется внутри трафарета, затем поворачивается вместе с ним.
Это этап 1 из шести; очередь и разведка описаны в REPAIR_STAGES.md.


В 0.3.5 камера плавно переходит между стоячей и присевшей высотой по найденной
кривой Deadlock. Если отпустить присед во время перехода, камера начинает
подниматься от текущей высоты. Этап 2 готов к ручной проверке.


В 0.3.6 обычный присед доступен только на земле: Ctrl в воздухе не опускает
камеру и не включает присевшую позу. Двойное нажатие Ctrl для дэша вниз и
удержание Ctrl для скольжения после приземления сохранены.
