# Haze для Minecraft — личный проект

Рабочая версия переноса Haze из вашей установленной Deadlock, сборка 25917577 от 13 октября 2026 года. Точное совпадение всех механик, камеры и интерфейса пока не достигнуто. Отличия и проверки записаны в MODLOG.md.

## Запуск текущей сборки

Minecraft **1.21.11**, **Java 21+**, **Fabric Loader 0.19.5+**. Поместите `deadlock-haze-0.1.0-dev.jar` в папку `mods` этой версии Minecraft. Fabric API включён внутрь JAR. Для первого запуска используйте отдельный мир.

- **F6** — Стив / Haze.
- **W A S D** — движение; **Shift** — рывок; **Ctrl** — приседание / скольжение; **Space** — прыжок.
- **ЛКМ** — стрельба; **ПКМ** — прицеливание; **R** — перезарядка.
- **1** — Sleep Dagger; **2** — Smoke Bomb; **3** — пассивная Fixation; **4** — Bullet Dance.
- **Q** — удар; **F** — парирование.
- Удерживайте **Alt** для курсора и улучшений; **Alt + 1–4** улучшает соответствующее умение. Очки способностей бесконечны.

Канат и зиплайн исключены по вашему требованию.

JAR содержит преобразованные ресурсы вашей Deadlock и предназначен для личного использования. Ничего не загружается в интернет. Проект и локальный Git находятся на диске D:. Извлечённые ресурсы игры исключены из Git.

## Сборка

`Build.ps1` запускает программные проверки и создаёт JAR в `build/libs`. Подготовленные личные ресурсы необходимы для сборки. Конвертеры и лабораторные данные описаны в MODLOG.md. Тестовый сценарий Minecraft включается только специальным параметром разработки.
