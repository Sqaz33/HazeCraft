# Сборка движения 0.2.0

Minecraft **1.21.11**, **Fabric Loader 0.19.5 или новее**, Java 21 или новее.
Положить `deadlock-haze-0.2.1-dash-fix.jar` из `dist` в папку `mods`
нужного экземпляра Minecraft. Заменить предыдущий JAR Haze, чтобы одновременно
не загружались две версии. Fabric API и ресурсы включены в этот один файл.

F6 — Стив/Haze. WASD — движение, Space — прыжок/двойной прыжок/отскок/подъём
на уступ, Shift с направлением — деш, Ctrl — приседание/скольжение,
двойной Ctrl в воздухе — рывок вниз, F — парирование. Для деш-джампа нажать
Space через 0,3–0,55 секунды после начала деша. Удерживать Ctrl при приземлении
после него для перехода в скольжение. Боковой отскок требует близкой стены и
положительного остатка стамины; первый отскок бесплатный, следующие стоят 0,5.

Это промежуточная сборка по просьбе пользователя. В неё перенесены подтверждённые
правила из текущего локального Deadlock build 25939744. Добавлены независимые
характеристики персонажа, расчёт с границами команд 64 Гц, захват коротких нажатий,
исправления прыжков и отскоков, сохранение скорости скольжения и отдельные сегменты
стамины. Модель и прежнее исправление её смещения при анимациях сохранены.

Полное совпадение движения ещё не достигнуто: остаются точные столкновения,
угловые отскоки, часть воздушного деша и переходов скольжения, очереди действий
и точное время событий ввода. Доведение модели движения отложено до следующей
команды пользователя. Канаты, зиплайны, вентиляторы и батуты не добавлены.

Проверено 52 программными тестами и запуском реального клиента Minecraft.
Файлы предназначены для личного локального использования; публикации не было.
