# HazeCraft

Личный Fabric-мод для Minecraft 1.21.11: Haze из Deadlock, движение, оружие,
способности и экспериментальный магазин. Внутреннее имя мода — `haze`,
имя JAR — `deadlock-haze`. Текущая версия: **0.3.14-item-rules**.

Исходники, Gradle Wrapper, конвертеры, тесты и история разработки находятся
в этом репозитории. Подробное управление и ограничения: [README.ru.md](README.ru.md),
[SHOP_STATUS.md](SHOP_STATUS.md), [MODLOG.md](MODLOG.md).

## Сборка и восстановление

Требуются Windows, JDK 21 или новее и доступ к зависимостям Fabric/Gradle.
JDK задаётся через `JAVA_HOME` либо `./Build.ps1 -JavaHome 'C:\path\to\jdk'`.
Зависимость от JDK внутри ExpeditionCraft удалена.

Подготовленные ресурсы личной копии Deadlock хранятся отдельно от Git:
в приватном выпуске `archive-2026-10-18`, файл `HazeCraft-private-resources.zip`.
Распакуйте его в корень клонированного репозитория, сохраняя пути `src/...`.
Затем выполните:

```powershell
./Build.ps1 -JavaHome 'C:\path\to\jdk'
python tools/package_preview.py
```

Готовый JAR появляется в `dist/`. Для игры нужны Minecraft 1.21.11 и
Fabric Loader 0.19.5+; Fabric API включён внутрь JAR.
Готовая личная сборка также сохранена в приватном выпуске.

Тестовые миры сохранены в `HazeCraft-worlds.zip`; распаковка в корень
восстановит `run/saves`. Ресурсы игры и личная сборка предназначены для
владельца исходной игры. Перед публичным распространением исключите чужие
ресурсы и подготовьте законный способ их локального извлечения.

Часть тестов использует исследовательскую лабораторию `D:\DeadlockHazeLab`.
Она хранится отдельно и не удаляется при очистке этой папки проекта.
Скрипты `tools/` содержат исходные пути этой лаборатории; это инструменты
исследования, а не переносимый установщик игры.

## Состояние

Проект экспериментальный; полнота переноса и известные ограничения описаны
в документации. Снимок GitHub сохраняет текущие изменения без заявления
о дополнительной игровой проверке. Существующая документация описывает
предыдущие этапы; актуальная версия определяется `gradle.properties`.

Код и документация разрабатывались с помощью OpenAI Codex. Архивирование
и проверка сборки выполнены OpenAI Codex. Ресурсы Deadlock принадлежат их
правообладателям; Fabric и сторонние библиотеки сохраняют собственные лицензии.
Новая лицензия на пользовательский код этим архивированием не назначается.


## Обновление 0.3.14

I открывает текущие характеристики; F8 → Персонаж меняет уровень (1–36).
При покупке предмета с imbue выбирается умение; СКМ меняет выбор.
Роли: hostile mobs — враги-герои, жители — союзники, остальные мобы — крипы.
Это промежуточная версия: полный перенос 156 предметов ещё не завершён.
Список исправлений, тестов и оставшихся механик — SHOP_STATUS.md.
Недостающие приватные native replay fixtures помечаются skipped при сборке,
а не создаются искусственно. Программные тесты предметов исполняются обычно.
